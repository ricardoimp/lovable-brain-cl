Run e Build

Build · desenvolvimento

Créditos gastos quando você pede algo ao agente do Lovable: criar telas, corrigir erros, conversar no chat, gerar imagens. É temporário: sobe quando um projeto está sendo construído e cai quando ele fica pronto. Você controla quanto gasta pelo tamanho e pela quantidade de pedidos.

Run · manter no ar

Créditos cobrados para os sistemas publicados funcionarem: banco de dados ligado 24 horas, tráfego de páginas, imagens e áudio entregues aos visitantes, funções, armazenamento e IA. É custo fixo e recorrente e cresce com a audiência. Reduz com cache, CDN e banco do tamanho certo.
